# Pop-up Sold Out — DOT Energy

Protótipo interativo do aviso de substituição temporária da embalagem do DOT Menta Fresh.

## Como visualizar

Abra o arquivo `index.html` no navegador ou sirva a pasta com um servidor local.

O fluxo inclui:

- comparação entre o pouch original e os 9 mini pouches;
- destaque para 25 sachês versus 27 sachês;
- explicação expansível sobre a mudança;
- opção para continuar com a embalagem temporária;
- formulário para aguardar a embalagem original.

Todos os recursos visuais e arquivos da fonte Montserrat estão incluídos em `assets-dot/`.
